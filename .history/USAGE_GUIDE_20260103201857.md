# Character Counter 插件使用指南

## 功能特性

- ✅ **实时状态栏显示**：在VS Code下方状态栏实时显示当前文件的汉字数量
- ✅ **智能计数器标签**：自动检测 `<counter>` 标签内的汉字和字母数量
- ✅ **自动分隔线**：当字符数达到目标值时，在最后一个字符所在行的下一行添加分隔线
- ✅ **自动生成新标签**：添加分隔线的同时自动生成一对新的 `<counter>` 标签
- ✅ **光标智能跳转**：光标自动跳转到新生成的计数器标签内

## 安装和运行

1. **安装依赖**：
   ```bash
   npm install
   ```

2. **编译扩展**：
   ```bash
   npm run compile
   ```

3. **测试运行**：
   - 按 `F5` 键启动 Extension Development Host
   - 或者使用 `Ctrl+Shift+P` 打开命令面板，选择 "Developer: Reload Window"

## 配置选项

在 VS Code 设置中配置目标字符数（默认30）：

**方法1：UI设置**
- 打开设置（`Ctrl+,`）
- 搜索 "Character Counter"
- 修改 "Goal Numbers" 值

**方法2：编辑 settings.json**
```json
{
  "charCounter.goalNums": 30
}
```

## 使用方法

### 基本使用
1. **状态栏监控**：打开文件后，状态栏右侧会实时显示当前文件的汉字总数
2. **使用计数器标签**：
   ```html
   <counter>
   这里是需要计数的文本内容，包含汉字和字母...
   </counter>
   ```

3. **自动处理流程**：
   - 当标签内汉字和字母总数达到目标值（默认30）时
   - 在最后一个字符所在行的下一行添加分隔线
   - 分隔线包含时间戳和目标数值
   - 自动生成新的 `<counter>` 标签
   - 光标自动跳转到新标签内

### 支持的文件类型
- 纯文本文件 (.txt)
- Markdown 文件 (.md)
- HTML 文件 (.html)

### 手动触发计数
- 使用命令面板（`Ctrl+Shift+P`）
- 输入 "Character Counter: Count Characters"

## 功能演示

**输入示例：**
```markdown
<counter>
这是一个测试文本，用于演示字符计数功能。
This is a demonstration of character counting.
当字符数达到目标值30时，会自动处理。
</counter>
```

**输出结果（当字符数≥30时）：**
```markdown
<counter>
这是一个测试文本，用于演示字符计数功能。
This is a demonstration of character counting.
当字符数达到目标值30时，会自动处理。
</counter>
-------------------202601032018|30END--------------------
<counter>
</counter>
```

**最终效果**：
- 状态栏显示：`汉字: X`（当前文件汉字总数）
- 分隔线格式：`-------------------时间戳(yyyyMMddHHmm)|goalNumsEND--------------------`
- 自动生成新标签并定位光标

## 故障排除

1. **分隔线未出现**：
   - 检查字符数是否达到目标值（默认30）
   - 确认标签格式正确：`<counter>内容</counter>`
   - 检查是否已存在分隔线（每个标签只有一条）

2. **状态栏不显示**：
   - 确认文件已保存
   - 检查文件类型是否受支持

3. **光标未跳转**：
   - 等待编辑操作完成（有100ms延迟）
   - 手动触发命令重新计数

4. **性能优化**：
   - 防抖机制避免频繁计算
   - 对于大文件可适当增加目标值
