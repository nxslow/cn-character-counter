# Character Counter VS Code Extension

一个功能完善的VSCode插件，实时显示汉字数量并在计数器标签内达到目标字符数时自动处理。

## ✨ 核心功能特性

- **📊 实时状态栏显示**：在VS Code下方状态栏实时显示当前文件的汉字总数
- **🏷️ 智能计数器标签**：自动检测 `<counter>` 标签内的汉字和字母数量
- **📏 自动分隔线**：当字符数达到目标值时，在最后一个字符所在行的下一行添加分隔线
- **🔄 自动续写**：添加分隔线的同时自动生成一对新的 `<counter>` 标签
- **🎯 光标跳转**：自动跳转到新生成的计数器标签内，便于继续编辑
- **⚡ 实时响应**：基于文本更改事件的智能防抖处理

## 🚀 使用方法

### 基本使用流程

1. **打开文件查看状态栏**：打开支持的文件后，状态栏右侧显示汉字总数

2. **使用计数器标签**：
   ```markdown
   <counter>
   您的文本内容可以包含汉字和英文字母...
   插件会自动统计有效字符数量
   </counter>
   ```

3. **自动处理**：
   - 当字符数达到目标值（默认30）时自动添加分隔线
   - 分隔线格式：`-------------------时间戳(yyyyMMddHHmm)|goalNumsEND--------------------`
   - 自动生成新的 `<counter>` 标签
   - 光标跳转到新标签内

### 配置选项

在 VS Code 设置中配置（默认值：30）：

```json
{
  "charCounter.goalNums": 30
}
```

## 📋 支持的文件类型

- 纯文本文件 (.txt)
- Markdown 文件 (.md) 
- HTML 文件 (.html)

## 🛠️ 安装和开发

1. **安装依赖**：
   ```bash
   npm install
   ```

2. **编译扩展**：
   ```bash
   npm run compile
   ```

3. **调试运行**：
   - 按 `F5` 启动 Extension Development Host
   - 使用 `Ctrl+Shift+P` → "Developer: Reload Window"

## 🔧 技术特性

- **智能字符统计**：仅统计汉字（\u4e00-\u9fa5）和字母（a-zA-Z）
- **防重复处理**：每个 `<counter>` 标签只会有一条分隔线
- **精确位置检测**：基于最后一个有效字符的位置添加分隔线
- **异步光标定位**：编辑完成后智能跳转光标位置
