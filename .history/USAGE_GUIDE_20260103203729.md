# Character Counter 插件使用指南

## 功能特性

- ✅ **实时状态栏显示**：在VS Code下方状态栏实时显示当前文件的有效字符数量（汉字和字母）
- ✅ **智能计数器标签**：自动检测 `<counter>` 标签内的汉字和字母数量
- ✅ **自动分隔线**：当字符数达到目标值时，在最后一个字符所在行的下一行添加分隔线
- ✅ **重新统计机制**：分隔线后继续统计下一个counter标签内的字符数量

## 安装和运行

1. **安装依赖**：
   ```bash
   npm install
   ```

2. **编译扩展**：
   ```bash
   npm run compile
   ```

3. **测试运行**：
   - 按 `F5` 键启动 Extension Development Host
   - 或者使用 `Ctrl+Shift+P` 打开命令面板，选择 "Developer: Reload Window"

## 配置选项

在 VS Code 设置中配置目标字符数（默认30）：

**方法1：UI设置**
- 打开设置（`Ctrl+,`）
- 搜索 "Character Counter"
- 修改 "触发分隔线的字符数量" 值

**方法2：编辑 settings.json**
```json
{
  "charCounter.goalNums": 30
}
```

## 使用方法

### 基本使用
1. **状态栏监控**：打开文件后，状态栏右侧会实时显示当前文件的有效字符总数
2. **使用计数器标签**：
   ```html
   <counter>
   您的文本内容可以包含汉字和英文字母...
   插件会自动统计有效字符数量
   </counter>
   ```

3. **自动处理流程**：
   - 当字符数达到目标值（默认30）时
   - 在最后一个字符所在行的下一行添加分隔线
   - 分隔线格式：`-------------------时间戳(yyyyMMddHHmm)|END--------------------`
   - 继续统计下一个counter标签内的字符数量

### 支持的文件类型
- 纯文本文件 (.txt)
- Markdown 文件 (.md)
- HTML 文件 (.html)

### 手动触发计数
- 使用命令面板（`Ctrl+Shift+P`）
- 输入 "Character Counter: Count Characters"

## 功能演示

**输入示例：**
```markdown
<counter>
这是一个超过30个字符的测试文本，当字符数达到目标值时会自动添加分隔线。
</counter>
```

**输出结果：**
```markdown
<counter>
这是一个超过30个字符的测试文本，当字符数达到目标值时会自动添加分隔线。
</counter>
-------------------202601032036|END--------------------
```

**最终效果**：
- 状态栏显示：`字符: X`（当前文件有效字符总数）
- 分隔线格式：`-------------------时间戳(yyyyMMddHHmm)|END--------------------`
- 继续统计后续counter标签内容

## 故障排除

1. **分隔线未出现**：
   - 检查字符数是否达到目标值（默认30）
   - 确认标签格式正确：`<counter>内容</counter>`
   - 检查是否已存在分隔线（每个标签只有一条）

2. **状态栏不显示**：
   - 确认文件已保存
   - 检查文件类型是否受支持

3. **性能优化**：
   - 防抖机制避免频繁计算
   - 对于大文件可适当增加目标值
